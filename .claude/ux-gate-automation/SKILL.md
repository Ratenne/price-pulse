# UX Gate 자동화 스킬

## 목표

**"구현 완료 = UX 자동 검증"**

구현 완료 후 자동으로 UI/UX를 검증하여 사용자 경험 품질을 보장합니다.

---

## 트리거 조건

다음 상황에서 자동 실행:
- [IMPLEMENTATION COMPLETE] 보고 감지
- "UX 검증", "문구 확인", "접근성 검증", "퍼널 검증" 언급
- "UI 검토", "UX 검토" 언급
- 구현 완료 후 자동 실행

---

## 실행 절차

### 1. 구현 완료 보고 확인

다음 정보를 수집:
- Task ID
- Feature 이름
- 변경된 파일 목록 (UI 관련)
- 화면/컴포넌트 목록

### 2. UI/UX 검증 항목 확인

다음 5가지 항목을 모두 검증:

#### 2.1 문구 검증
- 한국어 자연성 (번역체 아님, 자연스러운 표현)
- 톤 일관성 (전체 서비스 톤과 일치)
- 전문 용어 설명 (초보자도 이해 가능)

#### 2.2 퍼널 이탈 위험 감지
- 다음 행동 명확성 (사용자가 다음에 무엇을 해야 할지 명확)
- 오류 회복 (오류 발생 시 복구 방법 명확)
- 진행 막힘 지점 (사용자가 어디서 막힐 수 있는가)

#### 2.3 접근성 검증
- aria-label (모든 인터랙티브 요소에 접근성 라벨)
- 키보드 접근성 (키보드만으로 모든 기능 사용 가능)
- 색상 대비 (텍스트와 배경 대비 충분, WCAG AA 기준)

#### 2.4 오류 안내 검증
- 오류 메시지 명확성 (무엇이 문제인지, 왜 발생했는지, 어떻게 해결할 수 있는지)
- 오류 위치 표시 (어느 필드에서 오류 발생)
- 긍정적 톤 (사용자를 비난하지 않음)

#### 2.5 행동 유도 검증
- CTA 명확성 (주요 행동 버튼이 명확)
- 시각적 계층 (중요한 행동이 시각적으로 강조)
- 진행 단계 표시 (사용자가 어느 단계에 있는지 알 수 있음)

### 3. UX Report 생성

다음 형식으로 리포트 생성:

```markdown
# Claude UX Gate Report

## 1. 핵심 위험 (상위 5개)

1. **[Critical/High/Medium/Low] [위험 제목]**
   - 문제: [문제 설명]
   - 영향: [사용자에게 미치는 영향]
   - 우선순위: P0/P1/P2

## 2. 문구 개선

### [화면/컴포넌트명]
- **원문:** "[원래 문구]"
- **제안:** "[개선된 문구]"
- **이유:** [개선 이유]

## 3. 퍼널 이탈 위험

### 위험 지점 1: [위험 지점명]
- **문제:** [문제 설명]
- **제안:** [개선안]
- **우선순위:** P0/P1/P2

## 4. 접근성

### 문제점
- [문제 1]
- [문제 2]

### 개선안
- [개선안 1]
- [개선안 2]

## 5. 오류 안내

### 현재 오류 메시지
- **원문:** "[현재 오류 메시지]"
- **문제:** [문제점]

### 개선안
- **제안:** "[개선된 오류 메시지]"
- **이유:** [개선 이유]

## 6. 최종 판정

- **판정:** ✅ PASS / ⚠️ NEED FIX
- **이유:** [판정 이유]
- **Must Fix:** (Critical/High 위험만)
  1. [Must Fix 항목 1]
  2. [Must Fix 항목 2]
- **권장 Fix:** (Medium/Low 위험)
  1. [권장 Fix 항목 1]
  2. [권장 Fix 항목 2]
```

---

## 평가 기준

### PASS 조건
- Critical 위험 없음
- High 위험 3개 이하
- 기본적인 접근성 준수
- 오류 안내 기본 구현

### NEED FIX 조건
- Critical 위험 1개 이상
- High 위험 4개 이상
- 접근성 문제 다수
- 오류 안내 부재

# E2E Persona Test Prompts

전체 AI-SYSTEM 서비스를 **페르소나별로** 실제 사용자 입장에서 테스트하는 프롬프트입니다.

**핵심 원칙:** 모든 사용자(개발자/비개발자)는 **Decision → Execution → Task → Implementation → Deploy까지 A-Z 전체 여정**을 경험합니다.
- 진입 경로만 다름 (개발자 = 환경 설정 시작, 비개발자 = Decision부터 시작)
- 비개발자도 필요하면 Phase 5-8(구현/배포)은 개발자에게 위임하거나 직접 진행 가능

---

## 📑 페르소나별 목차

| 페르소나 | 대상 | 진입 경로 | 소요 시간 |
|----------|------|-----------|-----------|
| [DEVELOPER](#-developer-페르소나-e2e-테스트) | 개발자 (이준혁) | ai-system-landing → developer-start | ~3시간 |
| [NON_DEV](#-non_dev-비개발자-페르소나-e2e-테스트) | 비개발자 (김수진) | onboarding-portal → learner-start | ~2시간 |
| [LEARNER](#-learner-비개발자-페르소나-e2e-테스트) | 비개발자 (박민영) | onboarding-portal → learner-start | ~1.5시간 |

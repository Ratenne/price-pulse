# Workflow Rules: Decision Phase

## Decision Phase 워크플로우 규칙

### 단계
1. Context 작성 (`docs/00_context.md`)
2. Market 분석 (`docs/01_market.md`)
3. User 정의 (`docs/02_user.md`)
4. Journey 설계 (`docs/03_journey.md`)
5. Solution 정의 (`docs/04_solution.md`)
6. Decision 판정 (`/decision` Command)

### 출력물
- `decisions/[project-name].md` - Decision 기록
- `decision-lock.md` - Decision Lock 선언 (GO인 경우)

### 다음 단계
- GO: Execution Phase 진행
- HOLD: 추가 검증 후 재판정
- KILL: 프로젝트 종료

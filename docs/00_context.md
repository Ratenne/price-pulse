# 00. Context — PricePulse 공개 데모 배포

## 배경

PC 부품과 노트북 가격은 제품별 변동폭이 크지만, 일반 사용자는 현재 가격이 과거 범위에서 낮은지 높은지 판단하기 어렵습니다. PricePulse는 단순 가격 나열이 아니라 최근 6개월 범위, 현재 위치, 최근 방향을 함께 보여주어 구매자와 판매자의 판단을 돕는 데모입니다.

## 이번 실행의 목적

- 현재 구현된 목업 데이터 기반 웹 데모를 공개 URL에서 검증합니다.
- 핵심 화면과 가격 설명 방식이 사용자에게 이해되는지 확인합니다.
- 실시간 데이터·회원·거래 기능을 추가하기 전에 최소 비용으로 반응을 수집합니다.

## 전략적 적합성

- **상위 목표:** 가격 흐름 기반 거래 판단 경험의 사용자 가치 검증
- **기대 성과:** 공개 데모 사용자 5명 중 3명 이상이 현재 가격 위치를 이해했다고 응답
- **미달 시 조치:** 기능 확장 HOLD, 문구·정보 구조 재검증

## 사용자 근거 상태

- 현재 근거는 구현된 데모와 내부 사용성 점검입니다.
- 실제 외부 사용자 검증 데이터는 아직 없습니다.
- 따라서 이번 배포는 상용 서비스 출시가 아니라 제한된 공개 데모 검증입니다.

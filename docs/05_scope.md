# 05. Scope — 배포 범위 잠금

## 포함

- 현재 구현된 홈, 순위, 카테고리, 상품 상세, 안심거래, 404 화면
- 28개 로컬 시연 상품 데이터
- 반응형 UI, 테마, 인트로와 fallback
- 정적 Vercel 배포
- 자동 타입 검사, 단위 테스트, 프로덕션 빌드
- 배포 후 핵심 경로 smoke test

## 제외

- 실시간 쇼핑몰 API와 크롤링
- 회원가입, 로그인, 관심 상품, 알림
- 결제, 판매 등록, 에스크로
- 데이터베이스와 관리자 화면
- 가격 예측 또는 구매 추천 보장
- Production 자동 무승인 배포

## 범위 변경 규칙

제외 기능을 추가하려면 별도 Decision과 Architecture 갱신 후 진행합니다.

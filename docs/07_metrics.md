# 07. Metrics — 배포 성공 기준

## 기술 지표

- CI 성공률: 배포 후보 커밋 100%
- 주요 경로 응답 성공률: 100%
- 치명 브라우저 콘솔 오류: 0건
- High/Critical 의존성 취약점: 0건
- Production rollback 절차 확인: 완료

## 사용자 가치 지표

- 사용자 5명 중 3명 이상이 현재 가격 위치를 정확히 설명
- 사용자 5명 중 3명 이상이 구매·판매 관점 설명이 유용하다고 응답
- 핵심 판단 정보 도달 시간: 30초 이내

## 판정

- 기술 지표 미달: 배포 HOLD 또는 rollback
- 기술 통과·사용자 가치 미달: 기능 확장 HOLD, UX 재검증

# 03. Journey — 공개 데모 사용자 여정

## 1. 진입

사용자는 공개 URL로 접속하고 PricePulse의 목적을 확인합니다.

## 2. 탐색

- 홈에서 대표 가격 흐름과 변동폭 순위를 봅니다.
- GPU·CPU·노트북 중 관심 카테고리를 선택합니다.
- 순위 화면에서 카테고리와 정렬 기준을 변경합니다.

## 3. 판단

- 상품 상세에서 6개월 가격 범위와 현재 위치를 확인합니다.
- 구매자·판매자 관점의 설명을 읽습니다.
- 관련 상품과 비교합니다.

## 4. 결과

- 사용자는 현재 가격 수준을 이해합니다.
- 실제 거래 전에는 시연 데이터임을 인지하고 외부 가격을 다시 확인합니다.

## 실패 여정

- 직접 URL 접속 시 404가 발생하면 배포 설정 실패로 간주합니다.
- 이미지·영상 실패 시 대체 화면과 텍스트가 제공되어야 합니다.
- 잘못된 상품 ID는 서비스 404 화면으로 이동해야 합니다.

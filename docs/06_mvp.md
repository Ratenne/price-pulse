# 06. MVP — 공개 데모 배포 정의

## 목표

현재 구현된 PricePulse가 공개 URL에서 안정적으로 동작하고, 사용자가 가격 위치와 거래 관점을 이해하는지 검증합니다.

## 포함 기능

- 가격 흐름 홈 대시보드
- 전체 순위와 카테고리 탐색
- 상품 상세 가격 분석
- 안심거래 설명
- 모바일·데스크톱 반응형 화면

## 기술 범위

- React 19 + TypeScript + Vite 정적 웹 앱
- 로컬 mock 데이터
- Vercel 정적 호스팅
- GitHub Actions CI
- 서버·DB·프로덕션 환경 변수 없음

## 성공 기준

- CI의 타입 검사, 단위 테스트, 빌드가 모두 통과합니다.
- Staging과 Production에서 주요 6개 경로가 정상 응답합니다.
- 브라우저 콘솔에 치명 오류가 없습니다.
- 모바일과 데스크톱에서 핵심 콘텐츠가 접근 가능합니다.
- 사용자 5명 중 3명 이상이 현재 가격 위치를 이해했다고 응답합니다.

## 실패 기준

- 직접 URL 또는 새로고침에서 주요 화면이 열리지 않습니다.
- 가격 계산 테스트가 실패합니다.
- 시연 데이터 고지가 사용자에게 보이지 않습니다.
- High/Critical 보안 취약점이 해결되지 않습니다.

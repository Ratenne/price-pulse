# 04. Solution — 공개 데모 해법

## 해법

PricePulse는 28개 시연 상품의 6개월 가격 흐름을 현재 위치와 적정 범위로 가공해 웹 화면으로 제공합니다.

## 핵심 기능

1. 가격 변동폭·최저가 근접 상품 대시보드
2. 카테고리 필터, 정렬, 페이지네이션 기반 전체 순위
3. 상품별 가격 이력, 적정 범위, 구매자·판매자 관점 설명
4. 안심거래 기준 설명과 시연 데이터 고지

## 배포 해법

- Vite 정적 산출물 `dist/public`을 Vercel에 배포합니다.
- 모든 SPA 경로를 `index.html`로 rewrite합니다.
- GitHub Actions에서 타입 검사, 테스트, 빌드를 통과한 변경만 배포 후보로 인정합니다.
- Production 배포는 Vercel의 이전 배포 승격 또는 롤백 기능을 사용합니다.

## 경계

이 배포는 실제 가격 정확성, 거래 성사, 투자·구매 추천을 보장하지 않습니다.

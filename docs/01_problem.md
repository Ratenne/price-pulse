# 01. Problem — 해결하려는 문제

## 핵심 문제

사용자는 PC 상품의 현재 가격만 보고서는 지금 사도 되는지, 판매해도 되는지 판단하기 어렵습니다.

## 기존 방식의 한계

- 쇼핑몰은 판매가와 할인율 중심이라 장기 가격 범위를 알기 어렵습니다.
- 최저가만 보면 최근 상승·하락 방향을 놓칠 수 있습니다.
- 구매자와 판매자가 같은 데이터를 서로 다른 관점으로 해석해야 합니다.
- 가격 비교 정보가 많아도 거래 판단으로 연결되는 설명이 부족합니다.

## 이번 배포에서 검증할 문제

과거 가격 범위와 현재 위치를 시각적으로 제공하면 사용자가 현재 거래 시점을 더 빠르게 이해할 수 있는지 검증합니다.

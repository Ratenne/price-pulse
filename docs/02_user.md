# 02. User — 핵심 사용자

## 1차 사용자

### PC 부품 구매를 검토하는 일반 사용자

- GPU·CPU·노트북 가격을 여러 판매처에서 비교합니다.
- 할인율보다 실제 최근 가격 흐름을 알고 싶어 합니다.
- 복잡한 금융형 차트보다 명확한 구간 설명을 선호합니다.

## 2차 사용자

### 중고 또는 보유 제품 판매를 검토하는 사용자

- 너무 낮은 가격에 판매하지 않으면서 거래 가능성을 유지하고 싶어 합니다.
- 과거 평균과 적정 범위를 참고하고 싶어 합니다.

## 사용자 성공 상태

- 30초 안에 현재 가격이 낮음·중간·높음 중 어디인지 설명할 수 있습니다.
- 가격 흐름과 적정 범위를 근거로 다음 행동을 결정할 수 있습니다.
- 데이터가 시연용이라는 한계를 명확히 이해합니다.
